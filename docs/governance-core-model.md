# Governance Core Model

## Kernfluss

Signal -> Anlassraum -> Dossier -> Runde -> Mandat -> Umsetzung -> Impact

## Bürgerverständliche Projektion

Anliegen -> Region / Zuständigkeit -> Strukturierung / Qualifizierung -> gemeinsames Lagebild -> Debatte / Priorisierung / Evidenz -> Mandat / Handlung -> Umsetzung / Impact

Das ist kein zweiter Domain-Flow. Ein Anliegen tritt als direktes Signal oder reviewpflichtiger Signalkandidat in den Kernfluss ein. Place-/Registry-/Jurisdiction-Verträge klären Region und Zuständigkeit; Anlassraum und Dossier tragen Kontext und Lagebild; Dossier, Runde und Beteiligung tragen Evidenz und Debatte. Keine Stufe wird allein durch KI automatisch veröffentlicht, zusammengeführt oder zum Mandat erklärt.

## Signale
Relevanzhinweise aus Community, Feed, Journalismus, Event, Hinweis, Verwaltung.

## Anlassraeume
Kontextcontainer fuer Themen, Konflikte, Projekte und Events.

## Dossiers
Analytische Verdichtung eines oder mehrerer Anlassraeume.

## Runden
Deliberations- oder Abstimmungsraeume.

## Mandate
Formalisierte Uebergaenge in Beschluss / Auftrag / Projekt.

## Umsetzung
Operative Realisierung.

## Impact
Sichtbare Wirkung / Monitoring / Folgeprojekte.

## Leitregeln
- review-first
- publish-gated
- trust-separated
- funding-separated
- no auto publish
